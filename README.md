# SkillTrack 360° — Maharashtra

Public landing page and outcome-intelligence dashboard prototype built with React and Vite.

## Run locally

```powershell
npm install
npm run dev
```

Open the URL shown by Vite. The public landing page is available at `/`; the existing dashboard is available at `/dashboard`.

## Production build

```powershell
npm run build
```

The generated files are written to `dist` and can be deployed to Vercel.

## Notes

- Uses a synthetic demo dataset only.
- The dashboard modules and their current functionality are preserved.
- No `node_modules` folder is included in the source archive; run `npm install` after extracting it.
